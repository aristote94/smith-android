# SMITH Android

SMITH est un pack d'icônes Android et un widget domestique au style industriel sobre.

## Version 0.1

- aperçu graphique quotidien ;
- premier widget de démonstration ;
- structure de pack compatible avec les launchers tiers ;
- aucune connexion réseau ni donnée personnelle ;
- compilation automatique de l'APK avec GitHub Actions.

## Tester depuis un téléphone Android

1. Ouvrir l'onglet **Actions** du dépôt.
2. Ouvrir le dernier workflow **Build SMITH APK** réussi.
3. Télécharger l'artefact `smith-debug-apk`.
4. Décompresser le ZIP puis installer `app-debug.apk`.

Cette version utilise des informations domestiques fictives. Home Assistant sera ajouté ultérieurement.
